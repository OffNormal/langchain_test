## 2. 数据流

```
用户语音
  → 麦克风采集 (Web Audio API)
  → VAD 语音活动检测
  → ASR 语音→文本
  → 规则引擎 精确匹配 (<5ms)
      │ 命中? → 直接生成 DrawCommand
      │ 未命中 ↓
  → LangChain LLM Chain
      ChatPromptTemplate → ChatModel → OutputParser
      → NLUResult {intent, slots, confidence}
  → Command Parser
      坐标解析 + 颜色映射 + 参数校验 + 默认值填充
      → DrawCommand {action, target, params}
  → Drawing Engine (Fabric.js)
      → Canvas 渲染 + 反馈音效
```

## 3. 组件职责

### 3.1 ASR 引擎

负责音频采集（`getUserMedia`）、VAD 语音活动检测、语音转文字。
MVP 使用浏览器 Speech API（免费，50-150ms）；V1.0+ 升级为讯飞流式 ASR（中文准确率最高）；备选阿里云智能语音、百度语音识别。

### 3.2 NLU 引擎

负责意图分类（6 种）、槽位填充、指代消解、置信度评估。

**MVP 模式**: LangChain 直链 — 规则引擎优先（<5ms），规则不匹配走 LLM。LLM 低置信度时直接提示用户重述，不做复杂分支。

**V1.0+ 模式**: 引入 LangGraph StateGraph，管理意图路由、置信度分支、复合指令拆解和澄清对话回环。

### 3.3 Command Parser

NLU 输出 → 标准化 DrawCommand。负责坐标解析（相对位置→绝对坐标）、颜色名称→Hex 映射、参数校验与默认值填充。

### 3.4 Drawing Engine

基于 Fabric.js，负责 Canvas 渲染、对象 CRUD、图层系统、Undo/Redo 历史栈（最多 100 步）。

## 4. 关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 为什么 MVP 不用 LangGraph？ | LangChain 直链 | MVP 只需线性链路，LangGraph 的状态图增加复杂度但不增加价值 |
| 为什么规则引擎优先？ | 精确指令 <5ms | 大部分用户指令是高频简单指令，跳过 LLM 显著降低延迟 |
| 为什么用 Fabric.js？ | 非自研 Canvas | 成熟的对象模型、交互系统、序列化能力，开发效率远高于裸 Canvas API |
| 为什么国产 LLM？ | DeepSeek + 通义千问 | 中文理解好、延迟可控、合规、LangChain 有官方集成包 |
| 容错核心策略 | 快速执行 + 即时撤销 | 语音识别不可能 100% 准确，与其过度防御，不如降低纠错成本 |

## 5. 复杂指令处理（V1.0 规划）

MVP 不支持复杂指令。V1.0+ 通过 LangGraph 实现以下能力：

- **多步串联**: "画一个红色矩形, 然后在右边放一个蓝色圆形, 再用箭头连起来" → LLM 拆解为 3 步顺序执行。
- **空间推理**: 解析 "左边/上方/之间/等距分布" 等相对位置词，转换为绝对坐标。
- **批量操作**: "把所有红色图形变成蓝色" → 条件过滤 → 批量修改 → 打包为单次 Undo。
- **上下文管理**: 保留最近 10 轮对话，支持 "它""这个""那个" 指代消解。

**V1.0 LangGraph 状态图**:

```
[ASR] → [Intent Classify] → Router
  ├─ high_conf   → [Execute] → [Render]
  ├─ medium_conf → [Preview] → [Confirm?]
  └─ low_conf    → [Clarify] → 回到 ASR

Compound: [Decompose] → Loop [SubStep] → [Aggregate]
```

## 6. 风险与依赖

### 技术风险

| 风险 | 缓解措施 |
|------|---------|
| 中文 ASR 准确率不足 | 领域词汇白名单 + 拼音容错 |
| LLM 延迟不稳定 | 规则引擎兜底 + 超时重试 |
| LLM 服务中断 | LangChain 多模型热切换 |
| 浏览器兼容 | 首期限 Chrome/Edge 114+ |

### 产品风险

| 风险 | 缓解措施 |
|------|---------|
| 学习曲线过陡 | 渐进式引导 + 指令卡片 |
| 隐私顾虑 | 语音默认本地处理；云端需明示同意 |
| 语音疲劳 | 支持简短指令；PTT 模式 |

### 外部依赖与备选

| 依赖 | 备选 |
|------|------|
| 浏览器 Speech API | 讯飞 → 阿里云 ASR |
| DeepSeek API | 通义千问 → 智谱 GLM |
| LangChain | 锁定主版本号 |
| Fabric.js | Konva.js |
| Canvas API | Polyfill (Safari) |
