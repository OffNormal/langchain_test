# 纯语音控制绘图工具 — 产品需求文档（精简版）

> **版本**: v1.0 | **日期**: 2026-06-15 | **状态**: Draft

---

## 1. 产品概述

打造一款**完全通过语音驱动的智能绘图工具**，用户无需鼠标或键盘，仅凭自然语言即可完成绘图创作。

> "像与人对话一样画画——你说，它画。"

### 目标用户

| 用户 | 核心需求 |
|------|---------|
| 无障碍用户（上肢障碍者等） | 完全替代键鼠 |
| 教育工作者 | 授课时说边画 |
| 创意工作者 | 思维到图形的即时转换 |
| 普通消费者 | 零学习门槛 |

### 核心场景

1. 快速草图（"画一个三层架构图"）
2. 迭代修改（"把那个圆变大一点"）
3. 精确绘制（"在中央画一个半径200px的圆"）
4. 标注注释 + 导出分享

## 2. 功能范围

| 优先级 | 范围 | 说明 |
|--------|------|------|
| **P0 (MVP)** | 基础绘图 + 编辑 + 导出 | 必须闭环 |
| **P1 (V1.0)** | 自由绘制、图层、对齐、文字 | 核心体验 |
| **P2 (V1.1+)** | 模板、协作、智能建议 | 差异化 |

### P0 MVP 功能清单

- **5 种几何图形**: 直线、圆形、矩形、三角形、箭头
- **颜色操作**: 20+ 预设色 + 十六进制色值
- **画布导航**: 缩放、平移、重置视图
- **撤销/重做**: 支持多步撤销
- **文件操作**: 保存、导出 PNG/SVG、新建画布

### P1 V1.0 功能清单

- 自由绘制（方向+距离控制）、填充/油漆桶
- 图层管理、文字标注、图形编辑（旋转/对齐/复制/移动）
- 网格与吸附

### P2 V1.1+ 功能清单

- 渐变填充、自定义笔刷、模板系统
- 协作模式、智能建议、多格式导出（PDF/GIF）

## 3. 语音交互

指令语法: **`[动作] [目标对象] [参数]`**，兼容精确指令和自然口语。

| 类别 | 示例 |
|------|------|
| 创建 | "画一个红色的圆" |
| 修改 | "把填充色改成蓝色" |
| 删除 | "删除这个矩形" |
| 导航 | "放大到 200%" |
| 系统 | "撤销" / "导出为 PNG" |

**唤醒模式**: 空格键 PTT（桌面端默认），可选唤醒词 "嘿画板"。

**反馈闭环**: 语音波形 → ASR 文本回显 → 操作预览 → 完成确认（音效/Toast）。

**歧义处理**: 上下文推断（高置信直接执行）→ 乐观执行+可撤销（中置信）→ 主动澄清（低置信）。

## 4. MVP 成功指标

| 指标 | 目标 |
|------|------|
| 意图识别准确率 (Top-10 指令) | ≥70% |
| 端到端延迟 (P50) | <3s |
| 标准绘图任务完成率 | ≥60% |
| SUS 可用性评分 | ≥60 |

### MVP 验收标准

- [ ] 说"画红色的圆" → 画布出现红色圆形
- [ ] 说"把它改成蓝色" → 圆形变蓝
- [ ] 说"撤销" → 恢复到上一步
- [ ] 说"导出为 PNG" → 生成 PNG 文件
- [ ] ≥3 名用户成功完成引导流程

## 5. 约束与风险

| 约束 | 说明 |
|------|------|
| 浏览器 | Chrome/Edge 114+ |
| 网络 | MVP 需要联网（LLM 云服务） |
| 国产 LLM | DeepSeek-V4（主）/ 通义千问（备） |
| ASR | 浏览器 Speech API（MVP）/ 讯飞（V1.0+） |

**核心风险**: 中文 ASR 准确率、LLM 延迟、噪声环境可用性。  
**核心策略**: "快速执行 + 即时撤销"——降低单次错误的代价。
